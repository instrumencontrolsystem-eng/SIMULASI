Panduan Pemrograman PLC — Gas Plant LPG 40 MMSCFD

Dokumen ini dihasilkan otomatis dari data yang sama dengan sequencer dan tabel I/O pada digital twin, sehingga tidak bisa berbeda dengan perilaku yang Anda lihat di simulasi. Ikuti urutan bab 1 → 9; setiap langkah prosedur sudah dilengkapi kode Structured Text (IEC 61131-3) yang bisa disalin.

Urutan kerja yang disarankan
  1. Bab 3 — I/O: buat tag/variabel untuk seluruh sinyal (alamat Modbus sudah tertera, bisa langsung dipetakan dari/ke twin).
  2. Bab 4 — Interlock & keselamatan: program ESD, trip, dan output hard-wired lebih dulu dan letakkan di akhir scan.
  3. Bab 5 — Loop PID: parameter awal, mode MAN/AUTO, anti-windup, ramp.
  4. Bab 6/7 — Sekuens startup & shutdown per area: satu langkah = satu nomor state pada CASE; tiap langkah punya syarat → aksi → kriteria selesai.
  5. Bab 8 — Muat truk dan Bab 9 — pengujian dengan twin (uji tiap interlock dan restart setelah ESD).

1. Gambaran proses & area

Gas sumur (3 sumur SW-1..3) → separator inlet V-101 → contactor C-100 (absorpsi dengan lean oil) → sales gas. Rich oil → C-102 (deethanizer) → C-101 (debutanizer) → reflux drum D-101 → LPG ke storage T-201/T-202/S-201 → filling plant & muat truk. Panas dari hot oil heater H-101 (burner dengan BMS) ke reboiler E-101 (C-101) dan E-105 (C-102). Off-gas dikompresi K-101.

4.2 Logika keselamatan dasar (Structured Text)

(* ===== LOGIKA KESELAMATAN DASAR (dibaca dari PLC twin) — letakkan DI AKHIR scan agar mengalahkan sekuens ===== *)
(* ESD: latch; reset dengan HS_RST (pulsa naik) *)
IF HS_ESD OR (tGD_HH.Q) THEN ESD_ACTIVE := TRUE; END_IF;       (* tGD_HH: TON 3 s dari (MAX(AT_501..AT_506) > 40 %LEL) *)
IF rtRST.Q THEN ESD_ACTIVE := FALSE; (* + hapus semua latch trip, pompa kembali ke status awal *) END_IF;
(* Trip proses (semua latch, reset: HS_RST — kecuali yang tertulis otomatis) *)
TRIP_PSHH_001 := latch(PT_001 > 95.0);  reset otomatis bila PT_001 < 88.0 AND NOT ESD_ACTIVE;
TRIP_PSHH_101 := latch(PT_101 > 68.0);  TRIP_LSHH_101 := latch(LT_101 > 90.0);  TRIP_LALL_101 := latch(LT_101 < 5.0 sesudah pernah > 20.0);
TRIP_LSHH_100 := latch(LT_100 > 92.0);  TRIP_LALL_100 := latch(LT_100 < 5.0 sesudah pernah > 20.0);
TRIP_LALL_103 := latch(LT_103 < 5.0 sesudah pernah > 20.0);  TRIP_PSHH_102 := latch(PT_102 > 14.5);  TRIP_LALL_102 := latch(LT_102 < 5.0 sesudah pernah > 20.0);
(* Output hard-wired *)
SDV_001 := NOT (ESD_ACTIVE OR TRIP_PSHH_101 OR TRIP_LSHH_101 OR TRIP_LSHH_100) AND SEQ_CMD_SDV001;   (* fail-close: energized = BUKA *)

(* 1. Pembatas duty reboiler: naik mengikuti tekanan kolom (hindari overboil / sump kosong) *)

IF LIC_100.MAN THEN eL := LT_100 - 50.0; LIC_100.OP := LIMIT(0.0, LIC_100.OP + 2.2 * ((eL - eL_prev) + eL * tScan / 40.0), 100.0); eL_prev := eL; END_IF;
(* 3. Choke sumur dijaga agar tekanan pipa alir terkendali selama gas belum mengalir penuh *)
IF CHOKE_ASSIST THEN SW_CHOKE_SP := SEL(PT_001 > 60.0, SEL(FT_001 < 15.5, 100.0, 55.0), MAX(20.0, 55.0 - 2.5 * (PT_001 - 60.0))); END_IF;
(* 4. Pengisian awal lean oil (makeup) — startup pertama saja; di plant nyata: pompa makeup + lineup dengan LSH sump menutup lineup *)

Satu bay muat. Status 0–10 (IDLE, TUNGGU IZIN, BUKA ESV, START P-601, LAJU AWAL, LAJU PENUH, TOP-OFF, STOP, BLEED ARM, SELESAI, ABORT). Semua syarat keselamatan (grounding, arm cair & uap, gas bay, LSH 85 %, PSHH truk) diperiksa terus-menerus sejak status 2; pelanggaran apa pun → ABORT.

(* ===== SEKUENS MUAT TRUK LPG (satu bay) — PLC twin: 11 status ===== *)
(* konstanta: LOW=8 t/h, FULL=28 t/h, START_KG=300, TOPOFF_KG=700, ANT_KG=12, T_XV=15 s, T_PUMP=10 s, T_NOFLOW=20 s, T_BLEED=15 s,
              PT_HH=14.5 barg, GAS_HI=20 %LEL, SRC_LO=10 % *)
bSrcOk  := (ZSO_SDV_201 AND LT_201 > 10.0) OR (ZSO_SDV_202 AND LT_202 > 10.0) OR (ZSO_SDV_203 AND LT_203 > 10.0);
bArmOk  := ZS_ARM AND ZS_ARMV;
bReady  := ES_TRK AND bArmOk AND NOT LSH_TRK AND NOT ESD_ACTIVE AND bSrcOk AND NOT YF_P_601 AND AT_507 < 10.0 AND PT_TRK < (14.5 - 1.0);
(* ABORT (dari status 2..8): ESD, grounding hilang, arm terlepas, gas bay > 20 %LEL, LSH_TRK (85 %), PSHH_TRK, fault P-601,
   tidak ada tangki sumber, tak ada aliran 20 s, XV-VAP tak terbuka (>5 s), XV gagal buka (15 s), P-601 gagal start (10 s) *)
CASE iLoad OF
  0: (* IDLE *)        IF ZS_TRK THEN iLoad := 1; END_IF;
  1: (* TUNGGU IZIN *) IF NOT ZS_TRK THEN iLoad := 0;
                       ELSIF bReady AND HS_TRK THEN rBatch := 0.0; iLoad := 2; END_IF;   (* tekan START: preset kg dari HMI *)
  2: (* BUKA ESV *)    XV_VAP := TRUE; IF ZSO_XV_VAP THEN XV_TRK := TRUE; END_IF;
                       IF ZSO_XV_VAP AND ZSO_XV_TRK THEN iLoad := 3; END_IF;
  3: (* START P-601 *) P_601 := TRUE; FIC_TRK.AUTO := TRUE; FIC_TRK.OP := 0.0;
                       IF YR_P_601 THEN iLoad := 4; END_IF;
  4: (* LAJU AWAL *)   FIC_TRK.SP := 8.0;   IF rBatch >= 300.0 THEN iLoad := 5; END_IF;
  5: (* LAJU PENUH *)  FIC_TRK.SP := 28.0;  IF rBatch >= rPreset - 700.0 THEN iLoad := 6; END_IF;
  6: (* TOP-OFF *)     FIC_TRK.SP := 8.0;   IF rBatch >= rPreset - 12.0 THEN iLoad := 7; END_IF;
  7: (* STOP *)         P_601 := FALSE; XV_TRK := FALSE; IF ZSC_XV_TRK AND FT_TRK < 0.3 THEN iLoad := 8; END_IF;
  8: (* BLEED ARM *)    XV_BLD := TRUE; tBleed(IN := TRUE, PT := T#15s); IF tBleed.Q THEN XV_VAP := FALSE; XV_BLD := FALSE; iLoad := 9; END_IF;
  9: (* SELESAI *)      (* lampu hijau LOAD_DONE, arm boleh dilepas *) IF NOT ZS_TRK THEN rBatch := 0.0; iLoad := 0; END_IF;
 10: (* ABORT *)        (* semua ESV tutup, P-601 stop, alarm LOAD_ABORT; tunggu HS_RST *)
                       IF HS_RST AND NOT ESD_ACTIVE THEN iLoad := SEL(ZS_TRK AND (LSH_TRK OR rBatch >= rPreset - 200.0), 1, 9); END_IF;
END_CASE;
rBatch := rBatch + MAX(0.0, FT_TRK) * tScan / 3.6;   (* integrasi massa selama status 2..7 *)
LOAD_ACT  := iLoad >= 2 AND iLoad <= 8;   LOAD_DONE := iLoad = 9;
FV_TRK    := SEL(iLoad >= 3 AND iLoad <= 6, 0.0, FIC_TRK.OP);   (* katup hanya terbuka pada status 3..6 *)

10. Checklist pengujian (FAT) dengan twin

  1. Cold start: twin mode COLD & DARK → jalankan STARTUP OTOMATIS; semua 41 langkah harus selesai tanpa satupun trip PLC (±4,5 jam waktu plant; gunakan 300×).
  2. Mode per-langkah: pilih PER-LANGKAH; pastikan langkah tidak jalan sebelum syarat mulai ✓ dan tombol JALANKAN hanya aktif bila syarat lengkap.
  3. Interlock satu per satu: picu tiap interlock di bab 4.1 (mis. HS-ESD, PT-001 > 95, LT-101 > 90, FT-401 < 111) dan cek akibat serta cara reset sesuai tabel.
  4. Restart setelah ESD: ESD → tunggu plant turun → STARTUP; sekuens harus melewati langkah yang sudah terpenuhi dan tidak menimbulkan trip baru (kecuali HIPPS yang memang menunggu tekanan pipa alir turun).
  5. Shutdown normal → restart: shutdown sampai STANDBY, lalu STARTUP lagi; plant kembali ke kondisi tunak 40 MMSCFD.
  6. Timeout: tahan syarat selesai (mis. matikan sumur) dan pastikan alarm batas waktu langkah muncul.
  7. Fail-safe: matikan komunikasi — semua solenoid harus ke posisi aman (SDV tutup, BDV buka, SSV tutup).
